# PlanLoop · 本地时间块规划单文件应用

一个**本地优先、零依赖、单文件**的时间块规划应用：用固定「时间块结构」把一天的结构化决策前移，每天只负责往已经排好的时间块里填内容、执行、复盘，并把未完成任务沉降到跨日待办池。

面向从职场脱离的自由职业者 / 数字游民 / 独立开发者（你自己即目标用户）。无账号、无网络、无构建，双击即用。

---

## 快速开始

直接双击 `planloop.html`，用浏览器打开即可使用。无需安装、无需服务器、无需联网。

首次打开会：
- 在本地 `localStorage` 写入一份空数据（`v:2`）；
- 播种一个默认时间块结构：**黄金深度工作**（工作日 10:00–12:00）、**下午推进**（工作日 14:30–17:00）、**运动**（周一三五 17:30–18:30）；
- 物化今天并落在「今日」视图；
- **自动弹出新手引导**，分 5 步带你认识今日 / 状态徽章 / 复盘 / 待办池 / 模板；关闭后不再自动弹，之后可随时点顶栏「？」重看。

数据全程本地，随时可在顶栏导出/导入 JSON 备份换机。

## 五个页签

| 页签 | 作用 |
|---|---|
| **今日** | 每日操作主界面，采用**左侧 0–24 点纵向时间轴**：卡片按起止时间绝对定位，**卡片顶端=开始时间、高度=时段长度**（卡内不再显示时间文本）。可**按住卡片标题上下拖动**改变该块时段（时长不变、吸附到 5 分钟、不越出当日、仅作用于当日不回写模板）；每个块含色条、名称、可循环点击的状态徽章（未开始→已完成→部分完成→跳过）、任务名输入框、预估分钟、可展开的「详情」。顶部含当日概览（时间块数 / 已完成 / 已填内容）。 |
| **本周** | 周一起始连续 7 列概览，点任一块跳到对应日期的今日视图。遵守惰性物化：未定形的未来日显示结构实时投影。 |
| **复盘** | 计划 vs 实际：对照每块「任务 + 预估」与执行状态，可勾选未完成项放进待办池；底部 5 档心情 + 复盘文本框。 |
| **待办池** | 跨日未决任务收容池。每条显示来源 / 任务名 / 预估，可「分配」到某天的某时间块，或「删除」移出池子。 |
| **模板** | 时间块结构管理：增 / 删 / 改，含名称、起止、8 色色板、重复规则（每天 / 工作日 / 周末 / 自定义星期）。 |
| **顶栏** | 右侧：「？」引导重看、主题切换 ◐、导出 ⇩、导入 ⇧。 |

## 核心闭环

```
搭结构（模板）→ 今日填任务 → 点徽章标记状态 → 复盘勾选未完成项放入待办池 → 次日从池里分配到时间块 → 周视图可见
```

## 领域不变量（数据层硬约束）

1. **只影响未来**：结构增删改永不追溯改写已产出的计划与执行记录。
2. **每日快照解耦**：一天定形时把结构字段复制进当日，该日自包含、与模板无引用关系。
3. **惰性物化**：一天仅当「成为今天」或「首次被写入」时定形快照；其余未来日实时反映结构。

它们在 `tests/domain.test.js` 中有测试兜底。

## 运行测试

```bash
node tests/domain.test.js
```

退出码 `0` = 全部通过。测试会从 `planloop.html` 中用哨兵注释 `/*==DOM:CORE==*/` 与 `/*==DOM:GLUE==*/` 抽出领域纯函数层，包一层 `new Function` 后断言领域不变量与核心逻辑。因此**这两行哨兵及其中间的领域代码**是测试契约，改动会破坏测试。

## 数据存储

- **位置**：浏览器 `localStorage`，键名 **`planloop.v2`**。
- **结构版本**：`v: 2`。数据模型含 `templates`、`days`、`backlog`、`settings`。
- **种子标记**：键名 `planloop.seeded` 标记是否已播过默认结构（避免用户删光后再被重新播种）。
- **备份/迁移**：顶栏「导出」下载 `planloop-<日期>.json`；「导入」读取该 JSON 覆盖本地数据（导入前有覆盖确认）。这是本地应用数据得以存续的唯一通道（无云同步）。

## 后台文档关系

| 文档 | 关系 |
|---|---|
| `PRD.md` | 需求来源。§4 功能需求详述即本应用功能清单，§6 描述核心用户流程，§3 定义领域不变量。 |
| `CONTEXT.md` | 领域术语。 |
| `PROCESS_LOG.md` | 决策过程记录（含「新旧数据模型更替」等决策）。 |
| `SPEC.md` | 技术规格 + 实现计划。任务 1–5 已收尾（领域层，有测试兜底），任务 6（DOM 胶水层）、任务 7（README）由本项目达成。 |
| `planloop-prototype.html` | 旧一次性可点击原型（旧 v1 数据模型 / templateId 引用），仅作视觉与交互参考，**不代表最终实现**。最终实现见 `planloop.html`（v2 数据模型，块按 day 快照惰性物化）。 |

## 架构

- **单文件** `planloop.html`：领域纯函数层（可被 Node 测试）+ DOM 胶水层 + 样式，原生 HTML/CSS/JS，零依赖零构建。
- 领域层只做纯函数与状态改写，暴露 `createDomain(state)` 的 `projectBlocks / writeBlock / addToBacklog / assignFromBacklog / ensureToday / getMaterialized / exportState / importState / todayStr / addDays` 接口；胶片层负责渲染与事件，并在每次更改后把 state 持久化回 `localStorage['planloop.v2']`。
